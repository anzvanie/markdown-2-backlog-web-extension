詳細説明 / Detailed description
MarkdownをNulab Backlog記法に即座に変換できる拡張機能です。アカウント不要、データ送信なし。 ▼ 変換できる要素 ・見出し（# → *） ・太字・斜体・取り消し線 ・番号付きリスト・箇条書き ・リンク・画像 ・引用 ・コード（インライン・コードブロック） ・テーブル ・水平線 ▼ 使い方 1. ツールバーのアイコンをクリックし、左のパネルにMarkdownを貼り付けます。 2.「変換」をクリック、または入力するだけでリアルタイムに変換されます。 3. 結果をBacklogの課題・Wiki・コメントにコピーします。 ページ上のテキストを選択して右クリックし「選択範囲をBacklog記法に変換」を選ぶと、テキストがあらかじめ入力された状態でコンバーターが開きます。 ▼ プライバシー すべてブラウザ内で処理されます。ネットワーク通信・テレメトリ・アカウントは一切不要です。 ▼ 対応範囲 Nulab BacklogのBacklog記法モード（Markdownモードではない）プロジェクト向けに設計されています。

Detailed description
Paste any Markdown and get Backlog notation instantly — no account needed, no data sent anywhere. WHAT IT CONVERTS • Headings (# → *) • Bold, italic, strikethrough • Ordered and unordered lists • Links and images • Blockquotes • Code (inline and fenced blocks) • Tables • Horizontal rules HOW TO USE 1. Click the toolbar icon and paste your Markdown into the input panel. 2. Click "Convert" — or just start typing and watch it update live. 3. Copy the result to your Backlog issue, wiki, or comment. You can also select text on any page, right-click, and choose "Convert selection to Backlog notation" to open the converter pre-filled. PRIVACY Everything runs in your browser. No network requests, no telemetry, no accounts. COMPATIBILITY Designed for Nulab Backlog projects that use Backlog notation (not Markdown mode).

レビュアーへのメモ / Notes to reviewer
この拡張機能はすべての処理をローカルで行います。外部への通信は一切ありません。 使用する権限： - contextMenus: 右クリックメニューに変換項目を追加 - storage: ポップアップ間で下書きを保存 - activeTab・scripting: ユーザー操作時にアクティブタブから選択テキストを取得 - clipboardWrite: 変換結果をクリップボードにコピー リモートコードの実行はなく、収集・送信するデータもありません。
data_collection_permissions について： manifest.json の browser_specific_settings.gecko.data_collection_permissions.required を ["none"] に設定済みです（Firefox 新規申請の必須要件）。
